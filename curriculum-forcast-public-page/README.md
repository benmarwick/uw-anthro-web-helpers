These are for use with Extensions -> Apps Script on 'Anthropology curriculum forecast' at this URL:

https://docs.google.com/spreadsheets/d/1KTLT-PZzRjaZYCOdWGMEfAcZwEjby1mhXWoJMnUF8E0/edit?gid=10#gid=10

Conflict Report Script that checks for block schedule violations and overlaps of courses students are likely to want to take together. 

Scraper.gs that updates the sheet with NSc/SSc values for each course, and option requirements (core, required, approved). The runFullUpdate function in this script is set to run monthly to auto-update the sheet in case we edit the option pages or add/remove classes from the catalog

Code.gs and Index.html that produce the pleasant-looking, richly informative and interactive Anthropology Curriculum Forecast, to update, run the scraper in the Apps Scripts console, then click Deploy -> Manage Deployments -> New Version

Contents of some sheets are generated by cell functions, eg 'TA needs', showing which classes need what number of TAs.
